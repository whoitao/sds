# 优化 Admin 登录页面

## Context
用户提供的截图标注了两项明确调整：登录卡片标题与副标题水平居中，并移除“账号”“密码”两个表单项标签。保持现有登录流程、字段校验和视觉主题不变。

## 实施步骤
1. 修改 `apps/admin/app/login/page.tsx`，为标题和副标题设置居中对齐，并统一标题区域间距。
2. 删除账号、密码两个 `Form.Item` 的 `label` 属性，保留输入框图标、占位提示、自动填充和必填校验。
3. 不修改 `/api/auth/login`、登录状态、错误处理或登录成功跳转逻辑，不新增依赖。

## 验证
1. 运行 Admin 的 TypeScript 类型检查。
2. 启动 Admin 开发服务并打开登录页，确认标题及副标题居中、两个字段标签已移除，输入框和按钮布局正常。
3. 检查空表单校验、错误提示及登录提交逻辑未受影响。
