# 为 Admin 登录页添加丰收主题背景

## Context
最新截图要求缩小登录框，并添加符合“捎点啥”企业文化的背景，例如农业采摘与丰收主题的无声短视频。当前登录页使用纯色背景，卡片最大宽度为 420px，仓库中暂无农业媒体资源。

## 实施步骤
1. 使用视频生成能力制作一段 16:9、约 8 秒的写实农业采摘与丰收视频：温暖自然、镜头缓慢稳定、无字幕和水印，保存到 `apps/admin/public/media/admin-login-harvest.mp4`，并提取静态封面图。
2. 修改 `apps/admin/app/login/page.tsx`：在登录卡片底层加入全屏装饰视频，设置 `autoPlay`、`muted`、`loop`、`playsInline`，不显示控制器；将卡片最大宽度缩小至 360px，保留现有表单、校验和登录逻辑。
3. 修改 `apps/admin/app/globals.css`：添加登录页视频铺满、半透明遮罩和层级样式，保证表单清晰可读；视频加载或播放失败时使用静态封面，系统开启“减少动态效果”时仅显示封面。
4. 不新增第三方依赖，不引用外链媒体，不修改主题机制及认证相关代码。

## 验证
1. 运行 `pnpm --filter @sds/admin typecheck`。
2. 在现有 Admin 服务中检查桌面和窄屏显示：视频全屏、静音循环播放，卡片居中且宽度已缩小，无横向滚动。
3. 回归空表单必填提示、登录按钮及错误展示，确认交互不受影响。
